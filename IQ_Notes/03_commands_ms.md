# VS Code Commands & Keyboard Shortcuts (Windows)

All shortcuts below are the **default VS Code keybindings on Windows**. If a binding does not work, open **Ctrl+K Ctrl+S** (Keyboard Shortcuts) and search for the command name.

> Tip: `Ctrl+K` means "press Ctrl+K, release, then press the next key". Sequences like `Ctrl+K Ctrl+S` are two-step chords.

## 1) General

| Command | Shortcut | What it does |
|---|---|---|
| Show Command Palette | `Ctrl+Shift+P` / `F1` | Run any VS Code command by name |
| Quick Open (Go to File) | `Ctrl+P` | Jump to a file by typing its name |
| New Window | `Ctrl+Shift+N` | Open a new VS Code window |
| Close Window | `Ctrl+Shift+W` | Close the current window |
| User Settings | `Ctrl+,` | Open the settings editor |
| Keyboard Shortcuts | `Ctrl+K Ctrl+S` | Open and edit keybindings |

## 2) Basic Editing

| Command | Shortcut | What it does |
|---|---|---|
| Cut line | `Ctrl+X` | Cut the entire current line |
| Copy line | `Ctrl+C` | Copy the entire current line |
| Paste | `Ctrl+V` | Paste from clipboard |
| Delete line | `Ctrl+Shift+K` | Delete the current line |
| Insert line below | `Ctrl+Enter` | New line below, cursor moves there |
| Insert line above | `Ctrl+Shift+Enter` | New line above, cursor moves there |
| Move line up / down | `Alt+Up` / `Alt+Down` | Move current line (or selection) |
| Copy line up / down | `Shift+Alt+Up` / `Shift+Alt+Down` | Duplicate current line |
| Indent / Outdent | `Ctrl+]` / `Ctrl+[` | Add / remove indentation |
| Jump to matching bracket | `Ctrl+Shift+\` | Move to the paired bracket |
| Toggle line comment | `Ctrl+/` | Comment / uncomment current line |
| Toggle block comment | `Shift+Alt+A` | Wrap in `/* ... */` |
| Format document | `Shift+Alt+F` | Run the formatter |
| Start line / End line | `Home` / `End` | Move to start / end of line |
| Start / End of file | `Ctrl+Home` / `Ctrl+End` | Move to top / bottom of file |

## 11) At a Glance — Most Used

| Question | Answer |
|---|---|
| Open anything by name? | `Ctrl+P` (files) / `Ctrl+Shift+P` (commands) |
| Find & replace in one file? | `Ctrl+F` / `Ctrl+H` |
| Find & replace in whole project? | `Ctrl+Shift+F` / `Ctrl+Shift+H` |
| Rename a symbol everywhere? | `F2` |
| Edit many lines at once? | `Alt+Click` or `Ctrl+Alt+Up/Down` |
| Move a line fast? | `Alt+Up` / `Alt+Down` |
| Duplicate a line? | `Shift+Alt+Down` |
| Run / debug the project? | `F5` (start), `F9` (breakpoint), `F10` (step) |
| Open the terminal? | `Ctrl+`` |

## 12) TL;DR

- **`Ctrl+Shift+P`** is the master key — run any command by name when you forget a shortcut.
- Editing power keys: **`Ctrl+D`** (next match), **`Alt+Up/Down`** (move line), **`Shift+Alt+Down`** (copy line).
- Navigation: **`Ctrl+P`** (file), **`Ctrl+G`** (line), **`Ctrl+Shift+O`** (symbol).
- Debug flow: **`F5`** start → **`F9`** breakpoint → **`F10`** step over → **`Shift+F5`** stop.
- Customize anything in **`Ctrl+K Ctrl+S`** (Keyboard Shortcuts).
